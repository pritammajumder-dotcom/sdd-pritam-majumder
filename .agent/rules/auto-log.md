# Session Logging Requirement
You must maintain a log of our interactions to ensure an accurate audit trail of code changes and architectural decisions.

After you successfully complete any task, code generation, or significant analysis, you must append a summary to the `.ai-context/prompt_history.md` file located in the .ai-context directory.

The format for your appended log entry must be exactly as follows:
### [YYYY-MM-DD HH:MM]
**User Request:** (Summarize my original prompt in one sentence)
**Agent Action:** (Briefly describe what you did, the files you modified, or the solution you provided)
