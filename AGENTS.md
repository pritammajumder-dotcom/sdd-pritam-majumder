# INT AI-First Engineering Policy

This repository follows the INT AI-First Specification-Driven Delivery (SDD) methodology.
All agentic workflows must defer to the skills loaded in `.agents/skills/`.

## Authority Hierarchy
1. Local Repository First: `AGENTS.md` and `.agents/skills/`
2. Global Fallback Second: `~/.gemini/config/skills/`

## Lifecycle & Core Governance
Refer to `.ai-context/constitution.md` for project-specific governance and architecture constraints.
